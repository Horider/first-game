# Капли против лагеря

Браузерная tower defense в пиксельном стиле: из порталов лезут враги, а вы расставляете на своей половине поля лучников и щитоносцев.

В игре 5 уровней по 5 волн, на каждом появляется новая, более сильная капля. Защитники: лучник, мечник (оба прокачиваются до 2 уровня) и щитоносец. Прогресс и звёзды сохраняются в браузере.

Играть: https://horider.github.io/first-game/ (публикуется из основной ветки репозитория).

## Как играть

- Кликните по карточке защитника вверху, затем по свободной клетке на зелёной половине поля.
- Карточки с цифрой 2 сразу ставят защитника второго уровня. Чтобы прокачать уже стоящего лучника или мечника, кликните по нему без выбранной карточки, когда над ним горит зелёная стрелка.
- Кликайте по выпавшим монетам, чтобы забрать их сразу. Через 5 секунд они сами улетят в копилку.
- Капля, доползшая до стены, забирает сердце. Потеряли все три сердца, уровень проигран.
- Наведите на карточку или выберите её, чтобы увидеть силу, скорость и жизнь защитника по 10-балльной шкале. Клик по капле показывает её характеристики.
- Пробел или кнопка ⏸ ставит паузу. Кнопки x1, x2, x3 (или клавиши `1`, `2`, `3`) меняют скорость игры. `Esc` снимает выбор карточки.

## Разработка

```bash
npm install
npm run dev      # локальный сервер с перезагрузкой
npm test         # тесты игровой логики (Vitest)
npm run check    # проверка типов
npm run build    # сборка в dist/
```

Режим отладки: добавьте `?debug=1` к адресу. `M` даёт +1000 монет, `N` запускает следующую волну, `W` даёт мгновенную победу.

## Устройство

- `src/core/` правила игры без Phaser: состояние уровня и `tick(dt)`, системы волн, движения, боя, стрел, смертей, экономики и исхода.
- `src/data/` все числа баланса: защитники, враги, уровни, экономика.
- `src/scenes/`, `src/view/`, `src/ui/` отображение на Phaser 3: поле, спрайты, панель, экран результата.
- `public/assets/sprites/` спрайты 32×32 из пака 32rogues.
- `src/save/` сохранение пройденных уровней и звёзд в `localStorage`.
- `tests/` тесты логики, включая бота, который проверяет, что уровень 1 почти всегда проходим, а 5-й заметно сложнее.

Подробности в документах концепции и архитектуры проекта.

## Графика

Персонажи, капли, монета и стена взяты из пака [32rogues](https://sethbb.itch.io/32rogues) автора Seth Boyles. Спрайты вырезаны скриптом `scripts/import_32rogues.py`, у лучника и мечника первого уровня осветлён цвет кожи, защитники развёрнуты лицом к врагам. Спрайты однокадровые, поэтому все анимации (дыхание, выстрел, удар, походка, смерть) сделаны движением, масштабом и поворотом. Поле, порталы, стрелы и сердца нарисованы для этого проекта.
